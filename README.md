# Where the Last Light Sleeps

An atmospheric bilingual narrative mystery about memory, mercy, and the last lighthouse.

Over seven nights, lighthouse keeper Mira navigates drowned islands, answers broken radio calls, reconstructs lost memories, and decides which truths the survivors deserve to hear. Choices return during the final storm and lead to four endings, including a hidden conclusion.

## Play

Download the current Windows build from [itch.io](https://waebzip.itch.io/the-last-light-sleeps).

- English is the default language.
- A complete Korean translation is available under **Settings → Language / 언어**.
- Expected playtime is 2+ hours.
- The game runs offline and saves progress locally.

## Development

Requirements: Node.js and npm.

```bash
npm install
npm test
npm start
```

Build a portable Windows release with:

```bash
npm run dist:win
```

## Repository scope

This repository contains the game source, localization pipeline, tests, documentation, and store artwork. Generated executables, packaged Electron runtimes, ZIP bundles, and dependencies are excluded from Git.
