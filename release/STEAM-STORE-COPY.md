# Steam Store Copy Draft

## Title

마지막 빛이 잠든 곳

## Short Description — Korean

일곱 밤 동안 기억의 섬을 항해하고, 한 사람의 희생이 어떻게 기억될지 결정하세요. 선택이 다음 날의 항로와 마지막 방송, 네 가지 결말로 돌아오는 2~3시간 분량의 아름다운 내러티브 미스터리입니다.

## Short Description — English

Sail through seven nights on an island made of memory and decide how one sacrifice will be remembered. A beautiful 2–3 hour narrative mystery where choices return through later voyages, a final broadcast, and four endings.

## Recommended Tags

Narrative, Mystery, Adventure, Choices Matter, Atmospheric, Emotional, 2D, Puzzle, Singleplayer, Multiple Endings, Story Rich, Indie

## Feature Bullets

- 7일·42개 장면으로 구성된 완결형 미스터리
- 선택의 결과가 다음 날 항해와 결말에서 다시 돌아오는 28개 분기
- 직접 조타하는 밤바다 항해 7개와 신호·추론·기억 퍼즐
- 다섯 번의 폭풍 결정과 네 문장으로 만드는 최후 방송
- 일반 결말 3개와 숨겨진 새벽 결말
- 큰 글자, 고대비, 움직임·섬광 감소, 사운드 자막, 전 퍼즐 도움
