## 결론

- 업그레이드 전 콘텐츠·기능 점수: **8.5/10**
- 업그레이드 후 콘텐츠·기능 점수: **9.1/10**
- 네이티브 패키징 완료를 전제로 한 $5 구매 가치: **9.0/10**
- 베테랑 구매자 예상 별점: **4.6~4.7/5**
- 현재 Steam 출시 준비도: **4.2/10**
- 진행 차단 P0: **0건**
- 콘텐츠 P1: **0건**
- 일반 숙련자 초회 모델: **145~165분**

콘텐츠 목표 8점은 통과했다. 지금의 게임은 $5에 구매해 엔딩까지 플레이하고 추천할 수준이다. 다만 실제 인간 블라인드 테스트, 정식 OST·마스터링, 네이티브 빌드와 Steamworks가 없으므로 아직 5/5를 확정해 주장하지 않는다.

## 이번에 실제로 추가한 것

### 선택의 파문

- 항해 조우 선택지 28개 모두에 고유한 다음 장면과 엔딩 후일담을 연결했다.
- 한 회차에서 선택한 결과 14개를 모두 회수한다.
- 첫 12개 선택은 다음 날 항해의 연료 한계 또는 초반 안전 항로 정보에 실제로 영향을 준다.
- 마지막 날의 선택 2개는 폭풍 직전 네 페이지의 전용 결과 장면으로 돌아온다.
- 일지에 선택, 대기 중인 결과, 돌아온 결과, 실제 항해 효과를 기록한다.

### 반전 이후의 플레이

- 폭풍 선택 15개 각각에 고유한 즉시 여파와 엔딩 후 사회적 결과를 작성했다.
- 폭풍 뒤 살아 있는 해안에 보낼 최후 방송을 네 단계로 직접 만든다.
- 수신인, 사실, 약속, 서명을 각 세 선택지에서 고르고 완성된 네 문장이 최종 선택과 엔딩에 남는다.
- 방송 선택 직후 종료해도 재개 시 결과부터 이어지며 통계와 문장은 한 번만 반영된다.

### 감각 연출

- 장소와 날짜에 반응하는 절차형 음악, 파도, 바람, 폭풍, 종, 무전 효과음을 추가했다.
- 음악·환경음·효과음 독립 음량과 사운드 자막을 추가했다.
- 조명, 비네트, 레터박스, 폭풍 섬광, 피날레 연출을 추가했다.
- 움직임 감소, 섬광 감소, 시네마틱 강도 설정을 제공한다.
- 타이틀로 돌아가면 오디오 엔진을 비활성화하고 게임 재개 시 기존 컨텍스트를 재사용한다.

## 베테랑 완주 결과

- 7일·42개 본편 장면
- 선택 잔상 14개
- 밤 항해 7개·항해 조우 14개
- 선택 파문 14/14 회수, 전체 선택 매핑 28/28
- 신호 퍼즐·추론·기억 잠수 각 7개
- 밤 대화 7개
- 폭풍 선택 5개, 결과 매핑 15/15
- 최후 방송 4단계
- 진실 50 / 자비 49의 균형 경로
- 숨겨진 `dawn` 엔딩

장면, 항해, 조우 선택, 폭풍 선택, 방송 선택에서 중단·재개를 시험했고 선택이 중복 반영되지 않았다. 7개 항해는 검증된 최적해로 도움 없이 완주했다. 절차형 오디오는 단일 AudioContext, 음악·환경·효과음 버스 분리, 무음, 타이틀 비활성화, Web Audio 미지원 폴백을 통과했다.

## 남은 5/5 조건

1. 인디 내러티브 게임 팬 5~10명의 완전 블라인드 테스트
2. 중앙 플레이타임 125분 이상, 80% 이상이 120분을 넘는지 실측
3. 반전을 “놀랍고 공정하다”고 평가한 비율 70% 이상
4. 정식 작곡·효과음·전문 음량 마스터링
5. Electron 또는 Tauri 기반 Windows 빌드, 서명, 크래시 로그
6. Steamworks 업적·클라우드 저장·컨트롤러 표시
7. 실제 패드와 720p~4K, Windows 배율별 화면 QA
8. 스토어 캡슐·스크린샷·트레일러·크레딧·라이선스

내가 지금 구매자라면 **$5에는 산다**. 엔딩 뒤 리뷰는 현재 기준 **별 4.5개**에 가깝다. 위 조건까지 사람 대상 검증으로 통과하면 5/5를 줄 근거가 생긴다.
