# Where the Last Light Sleeps / 마지막 빛이 잠든 곳 — Bilingual Five-Star Cut

아름다운 기억의 섬을 일곱 밤 동안 항해하며, 한 사람의 희생이 죄·영웅담·사랑 중 무엇으로 남을지 결정하는 영어·한국어 2D 내러티브 미스터리 어드벤처입니다. **영어가 기본 언어**이며 설정의 `Language / 언어`에서 언제든 한국어로 바꿀 수 있습니다.

현재 제공물은 처음부터 네 가지 결말까지 완주 가능한 **Windows용 오프라인 게임**입니다. Five-Star Cut은 선택의 장기 결과, 폭풍 이후의 플레이, 절차형 사운드와 시네마틱 연출을 포함하며 Electron 기반 Windows x64 실행 파일로도 패키징되었습니다. 콘텐츠·기능 평가는 9.1/10으로 재검증했지만 Steamworks API 연동과 공개 출시 심사는 아직 완료되지 않았습니다.

## 실행

1. Windows 배포본에서는 `TheLastLight.exe`를 실행합니다.
2. 웹 배포본에서는 압축을 풀고 `PLAY.cmd`를 더블클릭합니다.
3. 또는 `index.html`을 Chrome, Edge, Firefox로 엽니다.

별도 설치나 인터넷 연결이 필요 없습니다. 브라우저가 로컬 파일 실행을 제한하면 폴더를 웹 서버로 열어 주세요.

## 언어 / Languages

- Default: English
- 번역: 한국어
- 첫 실행은 영어이며 언어 선택은 기기에 저장됩니다.
- 진행 중 언어를 바꾸면 게임이 다시 로드되고 기존 체크포인트의 기록 문구도 선택한 언어로 변환됩니다.

## 조작

- 섬 이동: `WASD` / 방향키 / 지도 위치 클릭
- 조사: `E` / 현재 위치 다시 클릭
- 항해일지: `J`
- 메뉴: `Esc`
- 밤 항해: 방향키 또는 `WASD`, `Z` 한 수 되돌리기, `R` 재시작
- 게임패드: 방향 패드 이동, `A` 확인, `B` 되돌리기, `Y` 도움/일지, `Start` 메뉴
- 저장: 장면·선택·항해마다 자동 저장, 메뉴에서 수동 저장

## Five-Star Cut 콘텐츠

- 7일 × 6개 장소 = 42개 본편 장면
- 42개 현장 선택과 이후 장면에 반영되는 108개 고유 성향 반응
- 강제 재방문 대신 하루 최대 2개, 총 14개를 직접 고르는 선택 잔상
- 암초·조류·스위치·문·구조자를 조합한 6×6 밤 항해 7개
- 항해 도중 멈춰 읽고 해석을 선택하는 주요 신호 조우 14개
- 항해 조우의 28개 선택마다 고유한 다음 날 결과와 결말 후일담
- 초회에 선택한 파문 14개 전부 회수: 12개는 다음 항해를 실제로 바꾸고, 마지막 2개는 폭풍 직전에 돌아옴
- 조율·청음·문장 복원·렌즈 정렬 신호 퍼즐 7개
- 매일 여섯 기록에서 증거 세 장을 잇는 추론 보드 7개
- 일상 사물 35개를 먼저 관찰한 뒤 시간선을 만드는 기억 잠수 7개
- 매일 주 인물 3답변 + 보조 인물 1답변으로 구성된 밤 대화
- 서로 다른 대가를 선택하는 마지막 폭풍 재구성 5단계
- 폭풍 선택 15개 각각의 즉시 결과와 고유한 엔딩 후일담
- 살아 있는 해안에 보낼 네 문장을 직접 만드는 최후 방송 4단계·12개 선택
- 성향과 완주 조건에 따라 달라지는 일반 결말 3개 + 비밀 결말 1개
- 인물별 고유 작별, 영구 엔딩/업적 보관함, 안전한 중단 재개
- 장소와 이야기 단계에 반응하는 절차형 음악·파도·바람·폭풍·효과음
- 장면 조명, 레터박스, 폭풍 섬광, 피날레 연출과 사운드 자막

## 접근성

- 큰 글자, 고대비, 움직임 감소, 섬광 감소, 즉시 이동
- 세 가지 텍스트 속도, 전체·음악·환경·효과음 독립 음량, 무음
- 사운드 자막, 시네마틱 강도 조절
- 모든 퍼즐과 항해의 불이익 없는 도움 기능
- 키보드·마우스·게임패드 흐름

## 플레이 시간

최신 소스 계측과 숙련 플레이 모델:

- 빠른 최적화 플레이: 약 95~115분
- 일반 숙련자 초회 중앙 구간: **145~165분**
- 천천히 읽고 일지를 확인하는 플레이: 약 205~240분
- 정상 독서 숙련자가 120분을 넘길 모델 확률: 약 85~95%

따라서 초회 중앙값 기준 2시간 목표는 달성했습니다. 다만 즉시 텍스트, 매우 빠른 독서, 최단 항로를 결합한 플레이어까지 최소 2시간을 강제로 묶지는 않습니다. 위 수치는 소스 기반 모델이며, Steam 상품 문구는 외부 블라인드 테스터 5명 이상에서 중앙값 125분 이상을 확인한 뒤 확정해야 합니다.

## 검증

- `node work/qa-five-star-cut.cjs`: 7일 전체 완주, 42장면, 14개 선택 파문, 항해/조우/추론/잠수/대화/폭풍/최후 방송/비밀 결말 통과
- `node work/qa-five-star-en.cjs`: 동일한 전체 완주를 영어 데이터 세트로 통과
- `node work/qa-localization.cjs`: 영어 기본값, 한국어 선택, 8개 현지화 스크립트와 런타임 문자열의 한글 잔존 여부 검증
- `node work/qa-sensory-engine.cjs`: 사운드 버스, 장면 전환, 음소거, 자막, 리소스 누수와 Web Audio 미지원 폴백 통과
- `node work/qa-veteran-cut.cjs`: 기존 본편 회귀 경로 통과
- `node work/validate-navigation.cjs`: 7개 항해 BFS 최적해와 이동 제한 통과
- Windows x64 실행 파일 생성, 격리 프로필 실행, Electron 렌더러의 실제 게임 HTML 로드 통과
- 배포 JavaScript 8개 파일 구문 검사 통과
- 진행 차단 P0 0건, 콘텐츠 P1 0건

세부 결과는 `QA-RESULTS.json`과 `REVIEW-ANALYSIS.md`에 있습니다.
